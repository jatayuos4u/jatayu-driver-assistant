# v0.8.6 Alpha — Kernel inspection feedback

The kernel evidence button now runs the existing read-only inspection in a worker thread. An indeterminate progress indicator and bilingual status line appear during inspection. A completion dialog distinguishes available logs, unverified correlations, and unavailable logs. PCI addresses are restored to the left edge after results update. No package installation or hardware verification is enabled.

Build and test on Debian 13 KDE before distributing. This is an alpha build.
