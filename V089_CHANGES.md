# Jatayu Driver Assistant 0.8.9 Alpha

- Device Details now translates category, confidence, explanation and Close button into Hindi.
- For allowlisted package hints only, a new button checks **local dpkg installed status** on a background thread.
- Status is informational; installed or missing does not prove firmware necessity.
- No new D-Bus methods, APT transactions, package installation, or privilege escalation.
- Package availability in APT repositories is not assessed by this version.
- Real installation remains disabled.
