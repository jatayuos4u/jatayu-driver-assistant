# Jatayu Driver Assistant Basic 1.2.0

This release focuses on hardware inventory, basic diagnostics and conservative recommendations. Repair Center and Testing Center are not part of the navigation. No driver installation or removal is offered.

The Recommendations page shows detected devices, bound kernel drivers and limited firmware package evidence. A bound driver does not prove full functionality, and an unbound device does not prove a missing driver. Package availability does not prove a package is needed.

Launch normally (without sudo). Kernel logs may be restricted. English and Hindi UI are provided. The `.deb` must be verified on a Debian 13 / KDE Plasma 6 system before public distribution.
