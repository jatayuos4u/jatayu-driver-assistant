# Contributing

Contributions to Jatayu Driver Assistant are welcome. Please open an issue before large changes. Submit small, focused pull requests with tests, and run `python3 -m pytest -q tests/` before submission.

By submitting a contribution, you affirm that you have the right to submit it under the project's GPL-3.0-or-later license. Do not include third-party code, icons, fonts, or screenshots without documenting their licenses and compatibility. Do not add privileged driver installation behavior without a security design and review.
