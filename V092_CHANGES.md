# v0.9.2 Alpha

Wi-Fi diagnostics now inspect up to 400 recent current-boot kernel messages (bounded to 64 KiB of output), looking for firmware-loading failure hints. Unavailable logs are distinguished from no matching errors. This is not device-specific proof and does not recommend or install packages. Both English and Hindi UI show the findings.

Installation remains disabled. Test on Debian 13 KDE Plasma 6 before distribution.
