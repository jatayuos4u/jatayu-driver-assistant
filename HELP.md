# Jatayu Driver Assistant 1.0.0 — Help

This application provides **read-only** diagnostics and APT previews for JatayuOS / Debian 13 KDE Plasma 6. It does **not** install, remove, or repair drivers.

Open **Help** in the application sidebar for English and Hindi guidance. Use **Overview** to scan, **Devices** to inspect hardware, **Repair Center** for cautious hints and Wi-Fi diagnostics, and **Testing Center** for demonstrations.

Kernel logs may be restricted for normal users; this is not evidence of missing firmware. Never disable kernel security settings or launch the whole GUI with sudo to bypass restrictions. Package hints do not establish a need for installation.

Official website: https://jatayuos.in
